# How We'll Study This

We should **not start by going through all 155 questions randomly**.

For your placement preparation, I recommend this progression:

```text
Day 1 → Python Fundamentals
Day 2 → Strings + Lists + Tuples
Day 3 → Sets + Dictionaries + Functions
Day 4 → OOP
Day 5 → Exceptions + Files + Modules
Day 6 → Iterators + Generators + Decorators
Day 7 → NumPy + Pandas + Python Libraries
Day 8 → Coding Problems
Day 9 → Tricky / Output Questions
Day 10 → Mock Python Interview + Revision
```

For every important question, I'll train you in this format:

> **Interviewer:** What is the difference between a list and a tuple?

**You should be able to answer naturally:**

> "The main difference is that a list is mutable, while a tuple is immutable. So we can modify elements of a list after creating it, but we cannot modify the structure of a tuple. I would use a list when the data needs to change, and a tuple when the data should remain fixed."

Then I'll give you the **technical explanation, example, common trap, and likely follow-up**.

That way, this becomes an **actual interview question bank**, not a collection of definitions.
