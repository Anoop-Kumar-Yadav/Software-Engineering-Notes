# 2.3 — Create the Public Entry Point

## 1. What we're doing right now

We are creating `packages/common/src/index.ts`, the **public entry point** of `@metriclink/common`.

It will re-export only the logger functionality and its public types that other MetricLink packages are allowed to consume.

## 2. Why this has to happen at this exact point

`logger.ts` now exists and compiles, but another package should **not need to know the internal file structure** of `common`.

Without `index.ts`, a service might be forced to do something like:

```typescript
import { createLogger } from "@metriclink/common/src/logger.js";
```

That exposes our internal structure. Instead, we want:

```typescript
import { createLogger } from "@metriclink/common";
```

So the dependency boundary becomes:

```text
services/url
     │
     │ @metriclink/common
     ↓
   index.ts
     ↓
 logger.ts
```

Later, when we add `createEnv()`, we will expose that through the same entry point.

## 3. Actual code

Create:

```text
packages/common/src/index.ts
```

```typescript
export { createLogger } from "./logger.js";

export type { CreateLoggerOptions } from "./logger.js";

export type { Logger, LoggerOptions } from "pino";
```

### Why `export type`?

These are TypeScript-only types:

```typescript
CreateLoggerOptions
Logger
LoggerOptions
```

They don't need to exist in the generated JavaScript.

Using:

```typescript
export type
```

makes that distinction explicit and works cleanly with:

```json
"isolatedModules": true
```

### Why export Pino's types?

Because consumers should be able to write:

```typescript
import type { Logger } from "@metriclink/common";
```

instead of importing Pino directly merely to annotate a logger supplied by our common package.

That keeps the service API centered around:

```text
@metriclink/common
```

rather than exposing implementation details unnecessarily.

---

## 4. What to check

Run:

```bash
pnpm --filter @metriclink/common exec tsc --noEmit
```

It should pass with **zero errors**.

Then verify the source structure:

```bash
find packages/common/src -maxdepth 1 -type f
```

You should now have:

```text
packages/common/src/logger.ts
packages/common/src/index.ts
```

At this point the first public API of `@metriclink/common` is:

```text
@metriclink/common
       │
       └── createLogger()
```

**Stop here.** Once this compilation check passes, we'll build the second shared capability: `createEnv()` for validated environment configuration.
